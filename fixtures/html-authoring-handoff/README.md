# HTML-authoring handoff fixtures

These synthetic request fixtures exercise the owner-local, metadata-only
`html-authoring-documentation-handoff@0.1.0-draft` boundary. They contain no
target project, source body, artifact body, source-map body, credential,
absolute path, raw locator, or host runtime state.

`accepted.request.json` is the only accepted input. Each `refused-*.request.json`
file isolates one fixed refusal family: version, identity, conformance, source
policy, private data, ordinary-map linkage, or host action.
